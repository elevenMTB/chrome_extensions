# Tab Group Helper Extension

## 本地加载

1. 打开 Chrome：`chrome://extensions/`
2. 开启“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择本目录：`tab_group_helper/extension`

## 使用方式

1. 点击扩展图标，打开 popup。
2. 使用“启用自动分组”控制自动处理。
3. 点击“打开配置”进入规则管理页。
4. 在配置页新增规则，或通过“导入 JSON”导入旧规则文件。
5. 点击“保存配置”后规则生效。
6. 可在 popup 中手动触发“整理当前窗口”或“整理全部窗口”。

## JSON 导入导出

支持导入两种格式：

1. 新格式：包含 `rules` 数组和可选 `settings`。
2. 旧格式：顶层为规则对象，规则内使用 `urlMatches`。

导出只包含规则和设置，不包含历史标签快照。
